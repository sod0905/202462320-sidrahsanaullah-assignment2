# AI Usage Report

## 1. AI Tools Used

I used Claude and GitHub Copilot while working on this assignment.

Claude was mainly used to help me plan the project structure and understand what files I needed.

GitHub Copilot was mainly used for some CSS suggestions and for helping with repetitive parts of the code.

### Specific Prompts and Tasks

- **Structure:** I explained the assignment requirements and asked for help organizing the files. I also asked what should go inside each file.

- **Layout:** I asked how to make the project cards change from multiple columns on a computer to one column on a phone. This helped me learn about `grid-template-columns` and responsive layouts.

- **JavaScript:** I asked for help with the dark and light mode button and how `localStorage` works. I also asked about checking the contact form using JavaScript.

- **Debugging:** When something was not working, I gave the code to the AI and asked what could be wrong. This occured fairly often, and i worked step by step while debugging.

- **Documentation:** I used AI to check my README and documentation and make sure I had covered the main requirements from the assignment.

## 2. Benefits and Challenges

### Benefits

AI helped me get started because I was not sure how to begin the project. Having examples made it easier for me to understand what I needed to create.

It was also useful when I did not understand something. I could ask questions about specific parts of the code instead of spending a long time trying to find the answer myself.

Another benefit was debugging. AI helped me notice small mistakes in my code, such as incorrect names or missing parts.

### Challenges

Sometimes the AI suggestions were more complicated than what I needed for this assignment. I had to remove some things and keep the website simple.

Another problem was that some of the content suggested by AI was too general. I had to change the information about myself, my skills, and my projects so that it actually described me.

I also realized that it is easy to copy code without really understanding it. Because of this, I asked for explanations when I did not understand something before using it.

## 3. Learning Outcomes

This assignment helped me understand CSS layouts better.

I learned that Flexbox is useful for arranging items such as navigation links and buttons, while CSS Grid is useful for arranging the project cards.

I also learned more about responsive design and how a website can change its layout depending on the screen size.

I also learned what `localStorage` does and how it can save a small amount of information in the browser, such as the user's selected theme.

Another thing I learned was that being specific when asking AI for help gives better results. For example, explaining what part of my code is not working is more useful than just asking the AI to fix everything.

## 4. Responsible Use and Modifications

I did not use the AI output without checking it first. I looked through the code and asked for explanations when I did not understand something.

I changed the written content so that the About Me section, project descriptions, and skills represent my own information.

I also changed parts of the styling instead of using every suggestion given by the AI.

When AI suggested code that I did not need or did not understand, I removed it instead of keeping it just because it worked.

I tested the website myself and made changes when I found problems.

I also made sure that the final project was not simply copied from an AI response. AI was used as a tool.
